# 课程知识点与项目对应

依据本次截图列出的Makefile和Git要求整理；课件原文未提供，页码对应需小组核对。下列命令在仓库根目录执行。

|知识点|项目位置|演示命令与判断|
|---|---|---|
|多文件编译、链接|src/*.cpp、gui/*.cpp；Makefile的TARGET/GUI_TARGET|make -j4；分别生成.o，最终链接arsenal-desktop|
|变量、目标、依赖、命令|Makefile的CXX、MODE、BUILD及模式规则|make -n；解释目标冒号后的依赖与Tab命令|
|自动变量|Makefile中的$@、$<、$^、$(@D)|定位编译规则和链接规则，分别解释输出、首依赖、全依赖、目录|
|函数|wildcard、patsubst、filter-out、addprefix|解释SOURCES到OBJECTS的路径转换|
|头文件增量构建|CXXFLAGS的-MMD -MP与末尾-include|先make，再touch include/engine.hpp并make；检查受影响模块|
|单模块增量构建|gui/inventory.cpp|touch gui/inventory.cpp后make；只编译inventory.o再链接|
|Qt代码与资源生成|moc_%.cpp、resources.cpp规则|touch resources/theme.qss后make；rcc、资源编译、链接|
|调试与构建隔离|MODE=debug与build/debug|make debug；查看-g3、-O0及独立产物|
|Shell参数与临时资源|launch.sh、scripts/demo.sh|bash scripts/demo.sh；解释参数、mktemp、trap、Here Document|
|Git暂存与提交|.git与本次修订提交|git status；git show --stat HEAD|
|分支、合并、标签|保留的feature分支及v0.1-core/v1.0/v2.0|git log --all --graph --oneline --decorate；git tag|
|真实远程托管|origin对应GitHub仓库|git ls-remote origin refs/heads/main；与本地HEAD比较|

历史提交由助手生成，用于教学演示，不是成员实际协作的证据。Shell是辅助流程；课程主线为Make构建与Git版本管理。

# 桌面版验证记录

环境：Ubuntu 24.04、GCC 13、Qt 6.4.2、GNU Make、Python 3。

## 已完成

- Release图形程序构建成功；生成moc与rcc代码并链接系统Qt动态库。
- Debug图形程序构建成功。
- 原引擎39项检查和十万次固定种子抽样通过；原CLI端到端测试通过。
- Qt Test包含事务存档、保存失败回滚、多件连续揭晓、桌面交互四项测试方法。
- 交互检查涵盖导航、五件入库、搜索清空、锁定、补给、真实开箱按钮、概率实验不改档案。
- Qt信号检查覆盖成功通知与失败通知；重启读取、CSV导出与备份内容通过检查。
- 实际渲染并检查补给站、背包、统计、实验室和开箱弹窗截图，位于previews目录。
- 增量构建确认：只修改inventory.cpp时间后，重编译inventory.o并链接。
- 资源构建确认：只修改theme.qss时间后，执行rcc、编译resources.o并链接，不重编译业务模块。
- 再次make无需执行编译或链接。

## 验证范围

GUI交互测试使用Qt offscreen平台，已验证事件处理与实际渲染；没有在用户的桌面、显示缩放、显卡或VS Code安装上运行。offscreen插件提示不支持propagateSizeHints，属于平台能力提示，测试未失败。

Qt新增部分本次没有完成泄漏检测验证。原版受限环境的LeakSanitizer限制参见旧验证记录，不将它当作Qt部分通过泄漏检测的证据。

代码以源码交付，不依赖交付环境生成的二进制。请在目标Linux桌面安装Qt开发包后自行make构建。

当前受限执行环境中，默认LeakSanitizer无法访问进程信息，报告环境错误；这不等于检查通过。只在遇到同类环境限制时可以运行：

```bash
ASAN_OPTIONS=detect_leaks=0 make sanitize
```

该命令仍检查地址错误和未定义行为，但不检查内存泄漏。普通Linux主机可先使用默认 `make sanitize`。

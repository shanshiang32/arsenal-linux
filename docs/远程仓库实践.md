# 真实远程仓库实践

目标仓库：https://github.com/shanshiang32/arsenal-linux 。

本次从用户上传源码包导入既有main、四个feature分支和三个版本标签，没有重新编造历史。原有历史为助手制作过程中的演示记录，不代表学生长期开发或多人协作。

操作顺序（仓库根目录）：

```bash
git remote -v
git status
git add README.md docs tools
git commit -m 'docs: complete course mapping, report, presentation and validation'
git push -u origin main
git push origin feature/gui-quality feature/qt-desktop feature/quality feature/statistics
git push origin --tags
git rev-parse HEAD
git ls-remote origin refs/heads/main
```

本页记录流程，是否成功以同目录evidence/remote-upload.txt中的实际终端输出和远端SHA为准。该日志在首次上传后追加提交，因此首次上传SHA对应其父提交；最终分支以GitHub当前main为准。
